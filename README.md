# Zoom 儿童画面裁剪

从 Zoom 屏幕录像里自动裁出某一位参与者（孩子）的视频小窗，输出一个尺寸固定的视频。
窗口被放大、缩小、拖动、部分拖出屏幕都会跟着走。全部在本机处理。

## 启动

双击 `start.bat`，浏览器会打开 <http://127.0.0.1:8756>。关掉那个黑色窗口就是退出。

## 使用

1. 把视频（或整个文件夹）拖进页面左侧。也可以粘贴本机路径，这样不会复制文件。
2. 认人的规则是"把实验者排除掉，剩下的那个就是孩子"。第一次会停下来让你点要裁的那个人，
   同一个视频里的另一个人默认记为实验者：有 Zoom 名字标签就记名字，没有标签就记人脸
   （名字可以从已登记的实验者里选，这样名字和脸就对上了）。之后的视频只要排除实验者后只剩一个人，
   就不再问；出现第三个人才会再问。只找到一个人、又没认出任何实验者时，照样裁，但任务会标成
   "Check who was cropped"，请确认裁的是孩子。
   实验者名单显示在选人页面下方，点 × 可以随时删掉；之后想换人点 Change person，换人不会改名单。
3. 处理完点开任务：左边是原视频加红框，右边是裁剪结果的预览，同步播放。
   时间轴上橙色高块是建议核对的片段，红色斜纹是没找到孩子画面的片段。
4. 哪段不对，就在 Manual fix 里填起止时间，在原视频上拖一个框或直接填坐标
   （也可以设为无画面 / 沿用之前的框），然后 Apply and re-export。
5. 看完一个视频点 Reviewed, next video，会自动跳到下一个还没核对的视频。
6. 结果先只存在工具自己的工作区里。点右上角 Export…，选要导出哪些视频、存到哪个文件夹
   （Browse… 会弹出系统的选文件夹窗口）、要哪些文件。同名文件已存在时会先问是否替换。

核对界面的快捷键：空格 播放/暂停，← → 跳 1 秒（Shift 跳 5 秒），, . 逐帧，P / N 上/下一处待核对。

## 导出的文件

| 文件 | 内容 |
| --- | --- |
| `名字_child.mp4` | 裁剪结果。帧的时间戳和原视频一致，音轨原样保留，可以直接和原视频对时间。 |
| `名字_segments.csv` | 每一段的起止时间、裁剪框坐标、状态和标记。 |
| `名字_report.json` | 同上，另含参与者名单、统计和人工修正记录（默认不勾选）。 |
| `crop_summary.csv` | 这次导出的每个视频一行：可见比例、待核对片段数、人工修正条数、是否已核对。 |

没有孩子画面的时段输出黑屏；窗口被拖出屏幕的部分也是黑的（画面位置保持不变）。

## 它是怎么认的

- **找窗口**：Zoom 的视频格子是固定 16:9 的矩形。程序找长直边，拼成矩形，
  要求每条边都有足够的边缘像素支撑。被拖出屏幕一部分、或鼠标悬停时顶上多出标题栏的情况单独处理。
- **跟窗**：每 0.5 秒检查一次；位置连续的格子算同一条"轨迹"，窗口被拖动时也跟着走；
  格子里的画面突然整个换掉（Zoom 重新排了座位）就断开。发现布局变了，就回头逐帧找出变化发生在哪一帧。
  单帧里看不清的边（两个深色画面之间的细分隔线）用最近几秒的平均边缘图补上。
- **认人**：把不可能是同一个窗的轨迹（同时出现在屏幕上）分开，把同一张脸、同一个格子、
  或外观相同的轨迹连成"链"。一条链的画面像真视频那样一直在微动、或者里面看到过人脸，才算一个人；
  幻灯片上的方框就这样被筛掉。
- **名字**：有 Zoom 名字标签就读标签（OCR）；没有标签时，看脸是否和以前记住的实验者一致；
  都没有就叫 Person A、Person B。
- **排除法**：孩子的脸被挡住、低头、凑太近时，那个窗认不出是谁。这时看同一帧里别的窗：
  实验者的窗认出来了，剩下的那个在动的窗就是孩子的（报告里标 inferred，不算待核对）。
  实验者也没认出来、但有个窗停在孩子刚才的位置上，就先当成孩子，标 held 让你核对；
  只剩一个窗、谁都没认出来，就不裁，标 unsure 让你核对。

## 已知限制

- 没有名字标签的录屏（1440×900 的 Mac 录屏）靠外观和人脸区分人，第一次会请你点一下谁是孩子；
  勾选"按脸记住实验者"之后，后面同一位实验者的视频就不再问。记住的只是人脸特征向量（一串数字），
  不存图片。分析完到选人之前，每个人的特征向量暂存在该任务的工作区目录里（faces.json），
  选定孩子的那一刻就删掉孩子的那份。换了人脸模型版本后旧记录自动失效。
- 一个视频里有两个孩子、或家长和孩子各占一个格子时，程序认不出哪个是孩子，会请你选。
- 两个人的显示名几乎一样（差一个字母）时可能被当成同一个人。
- 孩子关掉摄像头时，格子还在，会照常裁出来（报告里标记为"疑似摄像头关闭"）。
- 在五个样例视频（1920×1080 和 1440×900，共享幻灯片 + 视频小窗）上验证过，
  `python tests/regress.py` 会对照人工核对过的框重跑一遍。其他布局（画廊视图、非 16:9 的窗口）没有测试过，
  先拿一两个视频试一下再批量跑。

## 文件

```
run.py / start.bat      启动
zoomcrop/detect.py      在一帧里找 16:9 的视频格子
zoomcrop/analyze.py     全片分析：采样、跟窗、读名字、认脸、认人
tests/regress.py        回归测试（tests/truth.json 是人工核对过的答案）
zoomcrop/timeline.py    生成裁剪片段、标记、应用人工修正
zoomcrop/render.py      裁剪并编码
zoomcrop/server.py      本地网页服务
zoomcrop/static/        网页
workspace/              分析缓存、上传的副本、设置（可以整个删掉重来）
```
